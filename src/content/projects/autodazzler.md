Autodazzler automates rendering in Daz Studio. Instead of setting up and rendering each scene by hand, you describe the scenes and renders you want in a JSON file, and Autodazzler renders them all in one go.

It runs from within Daz Studio or from the command line, and is written in JavaScript for Daz Studio’s scripting engine.
